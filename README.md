## The joke

> I bought the dip. Then the dip bought a shovel, dug deeper, and now my portfolio is technically a mining operation.

One line, 115 characters: a trader buys the dip, the dip fights back
with a shovel, and the portfolio ends up reclassified as a mining
operation — the setup turns, and the punchline lands at the end.

## Run it

```sh
python3 main.py
```

This writes the joke to `/output/entry.txt` — one line, 115
characters, valid UTF-8, no trailing newline — and prints it to stdout.
Pure standard library, no network, no dependencies.
